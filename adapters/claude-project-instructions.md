# Project Instructions for Claude Projects

Always follow the `SKILL.md` file in Project Knowledge when planning cycling workouts, scaling Pro training diagrams, or generating Intervals.icu workout code.
Classify the rider into **Full Pro (`>= 4.5 W/kg`)**, **Scaled (`3.2-4.4 W/kg`)**, or **Double-Scaled (`< 3.2 W/kg`)** using their Weight (kg), CP20/CP60, and optional CP1 before generating their workout and fueling plan.
