# Goal-based Periodization / 目标导向周期化

多周、比赛与专项提升请求使用本参考；先按 `SKILL.md` 提问理解目标、训练史与不确定之处，再按需要参考课表结构。数据不足时可注明假设后先给方案，不要求填完专业问卷。训练剂量依据用户实际反应调整，不由职业模板或固定W/kg分档决定。这里是 Agent 的规划规则，不是现有计算器新增的命令参数。

## 1. 从用户材料保留的要点

- 由目标日期倒排阶段，逐步构建负荷，并在构建中穿插恢复和复测。
- 使用 A/B/C 课表优先级处理日程冲突；保持关键课质量，但疲劳与身体不适可推迟或取消任何课。
- Tempo/阈值配合低强度耐力；短冲刺配充分恢复；Surges & Settle 练习提速后回到稳定输出。
- 长距离需要逐步适应骑姿、补给和后段稳定性；车辆状态影响能否完成专项训练。

材料中的 Bob 数据是教练报告的单个案例，不是对照实验，也不是可承诺的提升率。20–30 秒全力冲刺仍可带来较高代谢和恢复负担；不能声称充分休息就“没有疲劳”。不要把固定周时长、固定测试周、心率区间混用或伤后照搬案例当成通用协议。热适应为本次用户新增目标，另按下列共识处理。

## 2. 把愿望变成目标卡

至少记录以下可用字段；缺失项标为待确认或明确假设：

```text
primary_goal / secondary_goals: 主目标与至多 1–2 个次目标
baseline / target / assessment: 当前水平、期望水平、验证方法
start_date / target_date / timezone / plan_weeks: 起止日期、时区与周数
event: 比赛日期、距离、爬升、预计用时、路况与环境（如有）
training_history: 最近4–6周均量、最长骑行、质量课经验
availability: 每周时长、各日上限、休息/力量训练安排
weekly_load: 期望周TSS范围/硬上限、最近真实负荷、容许浮动
distribution: 极化(PI>2)/金字塔/推荐、三强度区阈值与统计口径
readiness: 睡眠、疲劳、疼痛、近期中断与已适应的热环境
```

如目标和日期不可兼得，展示“延长周期 / 缩小目标 / 按当前准备度参赛”的取舍。不要为兼顾所有能力同时加入六种专项课。FTP 提升是期望值；同坡时间还受体重、风和设备影响，不能只归因于训练。

## 3. 能力目标 → 训练刺激 → 验收指标

### FTP / 持续阈值能力

- 起点：近期有效 FTP、测试协议、可连续完成的阈值时长。
- 从可完成的 Tempo/甜区或阈值总分钟开始，例如 2×10–15 分钟，再逐步延长；组数和强度不同时加。原模型 3 可缩放使用，VO2 课按需要替换部分质量课。
- 验收：同协议 FTP/20 分钟测试、同功率可持续时间及完成质量。20 分钟×0.95 是估计，不能混用不同测试直接比较。

### 爬坡能力

- 先区分短陡坡、3–8 分钟坡和20–60 分钟长坡。长坡偏持续阈值与配速，短坡偏短时功率和重复能力；长坡并非一律 VO2。
- 用坡长匹配的重复段，练节奏、变速与合适踏频；不要强制低踏频大扭矩。以安全路段或骑行台执行。
- 低强度课也可指定在缓坡完成，如2×20min坡上个人低区，保持齿比和功率上限；训练地形中的配速/骑姿，不因爬坡自动加功率。详见 [负荷与分布](load-and-distribution.md)。
- 验收：同坡/同路线时间、对应持续时间功率、后半段掉功率；记录天气、总质量与装备条件。

### 起伏路拉扯 / Surges & Settle

- 目标是提速后重新稳定输出，并在多次重复后保住质量。可用原模型 4 或下面的可控变式，不默认每次 all-out。
- 入门变式：2×8 分钟，稳态约 80–85% FTP，每组在第 2、4、6 分钟开始处，用 15 秒约 120–130% FTP 替换原稳态时间；组间轻松 4 分钟。按短时能力调整峰值。
- 进阶：先增加总有效分钟或重复次数，再考虑更高峰值。稳态内的提速是替换，不是把15/20秒追加到组时长。
- 验收：最后一组的冲刺重复性、提速后回稳态所需时间、动作和配速是否稳定。

### 5–15 秒短冲刺 / Miracle-style 训练

- 技术和安全条件允许、骑手恢复良好时，从4–6×6–10秒高质量冲刺与3–5分钟轻松恢复起步；根据短时功率与动作质量设置，不把150% FTP当作“全强冲刺”。
- 用户材料中的 Miracle #1 为3×20秒/4分40秒恢复，再3×10秒/4分50秒恢复，主组共30分钟；属可选进阶模板。20–30秒全力重复属于负荷更高的冲刺间歇，不能当作轻恢复点缀。
- 峰值、动作或重复质量明显下降就停止加组；不要在疲劳、热不适或重腿训练后的恢复课中强塞冲刺。
- 验收：同设备/同起始方式的5–15秒功率、有效重复次数、组间衰减；不要由短冲刺案例推断 FTP 必然上涨。

### 4 小时长距离耐受 / Durability

- 从最近能舒适完成的最长骑行逐步延长，示例为2小时 → 2.5小时 → 恢复 → 3小时 → 3.5小时 → 4小时；每一步可重复多周，取决于训练史与恢复，不是固定逐周加量要求。
- 大部分时段轻松耐力；只在耐受建立后少量加入比赛配速段。练骑姿、路线、补给、补水与停车策略，不能用“不停脚”牺牲交通安全。
- 验收：后1小时功率/RPE、相似地形下心率—功率变化、胃肠与骑姿舒适度及次日恢复；同条件比较，不用单个漂移阈值诊断耐力不足。
- 时间上限不允许4小时长骑时说明限制，可做部分准备，但不能声称室内2小时等效完整4小时户外专项。

### 热适应 / Heat Adaptation

- 先问目标赛事气候、已有热暴露、训练场景及既往热不适。热暴露本身占恢复预算，不能在既定高强度周上无条件叠加。
- 参考1–2周重复热暴露的共识框架，从本人可耐受的轻松骑逐步适应；环境温湿度、通风、时长与个体反应共同决定剂量，不规定每个人同样的高温/核心温度或每日暴露时长。
- 先保证正常补水、降温条件与随时退出；不以脱水、关闭全部散热或硬撑完成作为目标。首次尝试不放在比赛前一天，赛前减量期也不突然加热负荷。
- 验收：类似温湿度与功率下的心率、RPE、热舒适度和恢复情况。出现头晕、恶心或异常乏力即停止、降温；意识异常或倒地需紧急医疗处理。

## 4. 阶段和每周负荷

- **基础期**：确认基线，建立可持续训练频率、低强度容量和补给实践。
- **构建期**：围绕主目标渐进增加有效训练量，通常每周1–2次质量课，其余大部分轻松。
- **强度分布**：先问周TSS和极化/金字塔偏好；>10h更主动建议极化，新增时间优先低区。PI计算、周TSS约束与阈值未知处理见 [负荷与分布](load-and-distribution.md)。
- **专项期**：逐步接近坡长、反复提速、长距离或气候需求；模拟课替代已有课，避免额外堆叠。
- **恢复周**：可先减少约20–40%时间并缩短质量课，视疲劳调整；这是排课起点，不是适用所有人的固定百分比。
- **赛前减量**：较长备赛可用约1–2周框架、降低训练量并保留少量熟悉的强度。约40–60%的减量是研究群体参考，不是保证最优；明确比较基准及是否包含比赛本身。
- **非比赛目标日**：恢复后进行主目标测试，记录实际结果后决定下周期，而非默认比赛式减量。

8–14周仅为材料中的常见周期。实际由日期、准备度和目标确定；新手或恢复中用更保守起点。检查周总量不超过可用时间，力量/热适应也记录时间与恢复成本，休息周不得成为“补齐小时数”的训练周。

## 5. 优先级、复测与区间一致性

- **A**：最服务主要目标的关键课，如目标4小时耐受者的长骑；**B**：支持目标的次要课；**C**：可选轻松骑或辅助。优先级与强度分开标注。
- 仅时间冲突时先删 C、再缩 B，并可移动 A；恢复异常时可直接删 A。不要把漏掉的课塞进相邻日期，周内至少保留1天完全休息。
- 每次课后用全课/主组RPE、完成率、供能与主要限制感更新后续安排；读 [反馈循环](feedback-loop.md) 保存真实记录，别等到整个周期结束才调整。
- 基线可用近期有效数据，不一定再测；约每4–6周或阶段结束复测，评估替代质量课。测试前保证恢复、热身并用相同设备/设置，20分钟测试使用手动单圈与均匀配速；不强制短热身后耗竭，更不在伤病或异常疲劳时测试。
- 明确所用区间体系。常规 FTP 功率区间采用 Z1 <55%、Z2 约56–75%、Z3 约76–90%、Z4 约91–105%、Z5 约106–120%；更短时高强度另按持续时间与能力描述。边界取整不是生理阈值测量。
- 心率相对最大心率、心率相对阈值与功率百分比不可直接互换；短冲刺心率有滞后，不用于逐秒控强度。RPE 统一0–10量表。资料中的80–85% FTP “LT1/Z2”标签不能凌驾于这些定义。

## 6. 训练前装备与专项边界

长骑和专项前检查刹车、轮胎、传动、补给携带及码表电量；骑后擦除汗液与泥污。紧固扭矩、胎压、液压保养和悬挂存放遵从具体厂商说明，不从材料推导统一年度强制换油或所有车都必须悬挂。骑跑砖块训练仅在用户有铁三/两项目标时安排，不为纯骑行目标额外加入跑步负荷。

## 来源与证据边界

用户提供的周期化与专项训练材料作为待筛选输入；以上阶段安排和入门剂量是面向实际排课的综合建议，并非所有作者共同发布的标准协议。保留结构、调整绝对化表述，未独立核实的作者归属不作确定引用。

- [Coggan: Cycling Power Zones Explained](https://www.trainingpeaks.com/blog/power-training-levels/)：用于功率区间，不把 %FTP 当作个人乳酸检测。
- [Bernhardt: All-Out Miracle Intervals](https://www.trainingpeaks.com/blog/all-out-miracle-intervals-to-improve-average-power-for-endurance-events/)：教练案例与课表背景，不视为控制实验或保证效果。
- [Wang et al., 2023: endurance taper meta-analysis](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0282838)：减量研究参考，需按个体与赛程调整。
- [Racinais et al., 2015: heat consensus](https://pmc.ncbi.nlm.nih.gov/articles/PMC4602249/) 与 [IOC, 2023: sport events in the heat](https://pmc.ncbi.nlm.nih.gov/articles/PMC9811094/)：热适应、降温与个体化管理参考。
