# 历史职业课表结构参考

仅在需要具体刺激结构、用户主动要求参考职业课表，或比较训练变式时读取。这里的长版本与压缩示例是历史材料，不是按W/kg分配的处方；任何版本都可重新调整或不采用。不得由成绩档位推断耐受、糖原储备或必须完成的训练量。

先根据目标、近期已完成训练、时间和恢复确定训练剂量，再考虑是否借用结构。来源中的生理命名、时长、TSS和补给量都需核对；正文Skill与功率证据规则优先。不要默认原比例缩放，也不必给每个新课表制作三档版本。

以下保留六类历史课表的分段结构，供用户目标确实需要时参考。

另有 [图片课表库 I01–I11](image-workouts.md)：45/30+Z2坡、甜区+30/15、坡上VO2金字塔、VO2+冲刺、40/20、多个Over-Under与Threshold→VO2。保留来源结构/地形和未知项，与旧6模型一起按目标选择，不将文本新增模型当作已实现的Python枚举。

这些是历史示例，先核对分段总时长和个人可执行性。采用同一套区间定义：常规 FTP 功率 Z2 约 56–75%、Tempo 约 76–90%、阈值约 91–105%；不能把下面 80–85% FTP 的旧“LT1/Z2”命名当作个体实测 LT1。短冲刺、VO2 与无氧训练也不能合并为一个“>105% 全力区”。详见参考中的区间说明。

#### 模型 1: LT1 (Z2) Workout (有氧耐力与第一乳酸阈值)

- **生理目标**: 提升有氧基础、线粒体密度与 FatMax 脂肪供能效率，强化糖原节省能力。
- **来源长版本 (约4h02m，图中TSS ~215，Work: 250W=~2500kJ / 300W=~3000kJ / 400W=~4000kJ；个人输出须重算)**:
  - 热身: 30m Z1/Z2 自由骑 (50-60% FTP)
  - 第一组: 3x 20m @ LT1 (80-85% FTP)，组间恢复 3m @ 50% FTP
  - 中场恢复: 30m @ 50-60% FTP
  - 第二组: 3x 20m @ LT1 (85% FTP)，组间恢复 3m @ 50% FTP
  - 收尾耐力: 50m 自由骑 @ 50-60% FTP
- **压缩示例 A (90m, TSS ~85)**:
  - 15m 热身 (50-60% FTP) + 3x 20m @ 78-83% FTP (组间恢复 3m @ 50% FTP) + 9m 放松 (50-55% FTP)。
- **压缩示例 B (65m, TSS ~55)**:
  - 12m 热身 (50-60% FTP) + 3x 12m @ 75-80% FTP (组间恢复 3m @ 50% FTP) + 8m 放松 (50% FTP)。

#### 模型 2: Fast-Start VO2Max Intervals (快启最大摄氧量间歇)

- **生理目标**: 利用前 30 秒高功率爆发快速拉升摄氧量与心率，使后续稳态段充分停留在 VO2Max 区间。
- **来源长版本 (约 2h43m, TSS ~150, Work: 250W=~1600kJ / 300W=~1900kJ / 400W=~2500kJ)**:
  - 热身耐力: 45m Z1/Z2 自由骑 (50-60% FTP)
  - 主课表 (5x 4m45s，组间恢复 6m 下坡或 50% FTP): 30s 快启 @ 150-155% FTP + 4m 稳态 @ 100-105% FTP + 15s 尾段冲刺 (Sprint)
  - 收尾耐力: 60m Z1/Z2 自由骑 (最高 65-70% FTP)
- **压缩示例 A (80m, TSS ~85)**:
  - 15m 渐进热身 + 4x (30s @ 140% FTP + 3m30s @ 98-102% FTP + 15s @ 130% FTP，组间恢复 5m @ 50% FTP) + 15m Z2 收尾 (55-65% FTP)。
- **压缩示例 B (60m, TSS ~60)**:
  - 12m 热身 + 3x (20s @ 130% FTP + 3m @ 95-98% FTP + 10s @ 120% FTP，组间恢复 5m @ 50% FTP) + 15m Z2 收尾 (50-60% FTP)。

#### 模型 3: LT2 Workout (第二乳酸阈值容量堆叠 + Pro 阶梯激活热身)

- **生理目标**: 高容量阈值巡航配合短组间恢复推高乳酸清除极限；专属“阶梯渐进+双冲刺”热身预先激活有氧酶与快肌募集，尾段 75% 与 65-70% FTP 用于加速血乳酸氧化清除。
- **来源长版本 (约 2h36m, TSS ~180, Work: 250W=~1800kJ / 300W=~2200kJ / 400W=~2900kJ)**:
  - Pro 激活热身 (29m20s): 10m @ 50% + 2x (1m @ 50% + 30s @ 60% + 30s @ 70% + 30s @ 80% + 30s @ 95%) + 2x (2m @ 50% + 10s @ 150%) + 7m @ 50%
  - 主课表: 10x 9m @ LT2 (90-95% FTP)，组间恢复 1m30s @ 50% FTP
  - 排酸收尾: 10m @ 75% FTP + 13m @ 65-70% FTP
- **压缩示例 A (90m, TSS ~95)**:
  - 精简版阶梯激活热身 (19m20s: 首尾 50% 缩为 5m 与 4m) + 6x 8m @ 90-93% FTP (组间恢复 2m @ 50% FTP) + 收尾 (5m @ 75% + 6m @ 60-65% FTP)。
- **压缩示例 B (65m, TSS ~68)**:
  - 15m 阶梯激活热身 (1x 阶梯 + 2x 冲刺) + 4x 7m @ 88-92% FTP (组间恢复 2m30s @ 50% FTP) + 10m 收尾 (55-65% FTP)。

#### 模型 4: Z3/Z4 & Spikes (甜区/阈值复合微冲刺)

- **生理目标**: 模拟真实比赛中的集团拉扯，提升在有氧/甜区基底上反复承受无氧刺突（Spikes）并直接排酸恢复的能力。
- **来源长版本 (2h00m, TSS ~120, Work: 250W=~1300kJ / 300W=~1600kJ / 400W=~2000kJ)**:
  - 热身: 20m @ 50% FTP
  - 第一组 (20m 交替, 10x): 1m50s @ 80% FTP + 10s Spike > 150% FTP
  - 组间恢复 1: 15m @ 50% FTP
  - 第二组 (20m 变奏): 12m @ 95% FTP + 8m @ 85% FTP
  - 组间恢复 2: 10m @ 50% FTP
  - 第三组 (20m 交替, 4x): 3m @ 85% FTP + 2m @ 95% FTP
  - 收尾: 10m @ 65% FTP + 5m @ 50% FTP
- **压缩示例 A (80m, TSS ~82)**:
  - 12m 热身 + 第一组 6x (1m50s @ 80% + 10s @ 145%) + 8m 恢复 + 第二组 (8m @ 92% + 6m @ 85%) + 6m 恢复 + 第三组 3x (3m @ 85% + 2m @ 92%) + 9m 放松。
- **压缩示例 B (60m, TSS ~58)**:
  - 10m 热身 + 第一组 5x (1m50s @ 78% + 10s @ 135%) + 6m 恢复 + 第二组 (6m @ 90% + 6m @ 82%) + 5m 恢复 + 第三组 2x (3m @ 82% + 2m @ 90%) + 8m 放松。

#### 模型 5: VO2Max Workout (长有氧基底 + 2m/1m 过欠交替)

- **生理目标**: 在有氧消耗后进行高强度 2m/1m 交替（浮休保持在 75% FTP），强化疲劳状态下的摄氧能力与高功率抗衰减能力。
- **来源长版本 (3h31m, TSS ~200, Work: 250W=~2200kJ / 300W=~2600kJ / 400W=~3500kJ)**:
  - 前置耐力: 90m Z1/Z2 自由骑 (50-65% FTP)
  - 主课表: 3x 15m 交替组，每大组含 5x (2m @ 110% FTP + 1m @ 75% FTP)，大组间恢复 8m @ 50% FTP
  - 收尾耐力: 60m Z1/Z2 自由骑 (50-65% FTP)
- **压缩示例 A (85m, TSS ~88)**:
  - 20m Z1/Z2 热身 + 3x 12m (4x: 2m @ 106-108% FTP / 1m @ 72-75% FTP，大组间恢复 6m @ 50% FTP) + 17m Z2 收尾。
- **压缩示例 B (60m, TSS ~62)**:
  - 15m Z1/Z2 热身 + 2x 12m (4x: 2m @ 104-106% FTP / 1m @ 70% FTP，大组间恢复 6m @ 50% FTP) + 15m Z2 收尾。

#### 模型 6: 30/30s High-Torque & VO2Max Booster (短间歇高浮休 + 5分钟冲顶)

- **生理目标**: 30s 无氧/VO2Max 配合 80-90% FTP 的高强度浮休，最大化心肌搏出量与乳酸耐受，最后用 5 分钟 120% FTP 冲顶有氧上限，再转入极化 Z2 巡航。
- **来源长版本 (1h45m, TSS ~110, Work: 250W=~1000kJ / 300W=~1300kJ / 400W=~1700kJ)**:
  - 热身: 23m @ 50-60% FTP
  - 第一组与第二组: 2x 6m (6x: 30s @ 140-150% FTP + 30s @ 80-90% FTP)，组间恢复 10m @ 50-60% FTP
  - 恢复 2: 10m @ 50-60% FTP
  - 第三组 (冲顶): 5m @ 120% FTP
  - 收尾耐力: 45m Z1/Z2 @ 50-65% FTP
- **压缩示例 A (75m, TSS ~80)**:
  - 15m 热身 + 2x 5m (5x: 30s @ 135-140% FTP / 30s @ 80% FTP，组间 7m @ 50% FTP) + 7m 恢复 + 4m @ 112-115% FTP + 22m Z2 (55-65% FTP)。
- **压缩示例 B (60m, TSS ~58)**:
  - 12m 热身 + 2x 4m (4x: 30s @ 125-130% FTP / 30s @ 75% FTP，组间 6m @ 50% FTP) + 6m 恢复 + 3m @ 108-110% FTP + 21m Z2 (55-62% FTP)。
